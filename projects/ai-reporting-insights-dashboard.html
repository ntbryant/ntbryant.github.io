AI Reporting & Insights Dashboard

A dashboard that reports on how AI tools are used across the firm and what they cost. I led its build in Go and React.

My role
Lead contributor and primary author
Years
2026, in active development
Built with
Go, React 19, PostgreSQL
Approach
Built in-house

The problem

A firm that adopts AI tools needs clear reporting on how they are used and what they cost. Assembling that by hand does not scale.

What it does

The dashboard is the single place for reporting and insights on AI tool use and spend.

How it's built

  • A Go backend using pgx and sqlc for typed database access, with versioned migrations.
  • A React 19 dashboard with TanStack for data fetching and routing, built with Vite and styled with Tailwind.
  • One monorepo, so the API and the interface change together.

Outcome

  • Written primarily by me, with a small team contributing.
  • An example of a team building its own AI tooling instead of buying it.
